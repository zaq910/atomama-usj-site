# Atomama USJ Mobile-First Theme Skeleton

WordPress初心者でも管理しやすいように、トップページ導線を中心に最小ファイルで構成したテーマです。

## 方針
- スマホ最優先（Mobile First）
- 最重要導線として「よやくのり攻略」を最上位に固定
- 管理画面で編集しやすい（カスタマイザーで重要CTA URLのみ変更可）
- 将来的なページ追加（記事一覧・カテゴリ・プロフィール）を想定した拡張しやすい構造

## ファイル構成
- `front-page.php`: トップページ専用テンプレート
- `functions.php`: テーマ設定 / メニュー / CTA URLカスタマイズ
- `style.css`: モバイル優先スタイル
- `header.php`, `footer.php`, `index.php`: 基本テンプレート
